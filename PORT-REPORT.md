# Notion Rust port

This is the rank 10 Raycast Store port for **Notion** by **HenriChabrand**, owned by **notion**. The observed Store snapshot recorded 294,480 downloads and listed Windows and macOS. The independent package is `com.tezbar.native.notion` version 0.1.0, replacing `raycast.notion`. It uses schema 3, the native Rust process, protocol 1, and Tezbar **0.3.0-beta.12** or later. The repository field points at the immutable upstream directory. The SDK is locked to `1a11afc14693cc6463e0b95ae7d61991b4a60427`. [Store listing](https://www.raycast.com/notion/notion), [source commit](https://github.com/raycast/extensions/tree/459326f4f557692a79246dba2d013746f56d724b/extensions/notion), [SDK commit](https://github.com/almatkai/tezbar-extension-sdk-rust/tree/1a11afc14693cc6463e0b95ae7d61991b4a60427)

The source freeze records **87 original Git blobs** with SHA-1 Git object IDs, modes, and SHA-256 checksums. It retains the original package, its JS lockfile, application assets, metadata screenshots, all original command and tool source, and the two upstream license files. The target package retains byte-identical application assets, notices and the locked normal/build dependency notice closure for Windows x64 and Apple Silicon macOS. The native manifest carries the six original command IDs, three extension preferences, command preferences, launcher arguments and both platforms. The native token placeholder was shortened to `ntn_...`.

## API contract

The upstream lockfile pins Notion's JS client at 5.9.0, whose default is `2025-09-03`. The Rust port uses the documented `2026-03-11` API. It sends `position: {"type":"start"}` for prepend and uses `in_trash` for trash/restore. The previous source code implements prepend with an `after` reference to the first block. The new endpoint shape lets the port insert at the actual beginning without moving or deleting existing content. [Notion client 5.9.0](https://github.com/makenotion/notion-sdk-js/blob/v5.9.0/src/Client.ts), [migration guide](https://developers.notion.com/guides/get-started/upgrade-guide-2026-03-11), [append children](https://developers.notion.com/reference/patch-block-children), [update page](https://developers.notion.com/reference/patch-page), [update data source](https://developers.notion.com/reference/update-a-data-source)

The bearer token comes from the host password preference and is sent to the fixed HTTPS Notion origin. The extension does not write it to its local store or expose it in errors. Search and data-source queries retain opaque cursors and reject repeated cursor cycles. Notion service failures and rate limits are surfaced without echoing response bodies. The client avoids automatic write retries. Article capture uses a separate client with bounded redirects, download time and size. It resolves each destination, pins accepted public addresses and sends no Notion credentials.

## Known differences and verification limits

- This port uses an Internal Integration Secret. Raycast-managed browser authorization, refresh and reconnect depend on Raycast's OAuth provider and token storage. No browser sign-in is registered by this package.
- The seven original AI entries remain traceable in `UPSTREAM.json` and `upstream/`: `search-page-mentions`, `search-pages`, `get-page`, `add-to-page`, `create-page`, `get-databases` and `search-database`. Raycast tool registration, AI @mentions, selective read-resource handling and the packaged Knowledge Capture skill are source evidence. The Tezbar command host lacks those inbound contracts. The explicit Quick Capture AI summary uses the existing outbound provider call.
- Database records use a list. The Raycast Kanban lanes, saved property ordering/visibility, inline property actions, people/relation pickers and create/capture command Quick Links are not reproduced. People and relation fields accept IDs. Editing a relation or people list that might be partially materialized is suppressed to avoid overwriting unseen values. Direct page URL Quick Links are available. App opening depends on the OS handler or a host-supplied application path.
- Local pin and recent markers reorder current results by ID. Dedicated sections, Raycast state migration, and saved form defaults are absent. Notes lookup and date formatting support the common numeric/month/day patterns and quoted literals. Date dividers use a local calendar-date mention.
- Rendering and writes cover common text, links, headings, lists, to-dos, quotes, code and dividers. Markdown-to-block conversion and HTML article extraction differ from Martian and Mozilla Readability. Table and media conversion, arbitrary rich-text annotations, user name resolution, remote page icons, signed media previews, and authenticated or JavaScript-rendered articles are outside the preview scope. A preview has bounded content size, depth and request count. Block-count and nesting bounds are checked before submitting the form. Each request is checked against the byte limit before that request is sent; a multi-step operation can have created its parent before a later request fails.
- The tests use a synthetic account identity and a loopback service. No live workspace auth, write or clipboard operation was exercised. Windows/macOS GPUI desktop acceptance, an Apple Silicon build and publication are separate parent gates.

## Reproduce

Run `python scripts/verify-local.py` from this repository with the local Rust and Python toolchains. `reports/verification.json` records each gate and `reports/protocol-smoke.json` records the real executable loopback checks. The packager checks the runtime identity, frozen SDK revision, binary architecture, dependency notices, platform ZIP inventory and executable mode 0755. It refuses fixture-feature executables. `scripts/freeze-source.py` writes the source archive, SHA-256 and a complete file inventory under `dist/`.

Parent review repair: an explicit notes parent now scopes notes-root lookup and creation exclusively to that parent. A competing same-named global root cannot redirect the write. The JSONL regression also verifies that unscoped notes still follow opaque search cursors.
